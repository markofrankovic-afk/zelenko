# Google Play: tekstovi i slike

- `hr.txt`, `en.txt`, `de.txt` – naslov (do 30 znakova), kratki opis (do 80) i puni opis (do 4000).
- Slike zaslona 1080 × 1920 po jeziku: `hr-*.png`, `en-*.png`, `de-*.png` (karta, mjesto, ruta, gastro, izlet, putovnica, sigurnost).
- `naslovna-1024x500.png` – naslovna slika (feature graphic); izvor `naslovna.html`.
- `ikona-512.png` – ikona za trgovinu.
